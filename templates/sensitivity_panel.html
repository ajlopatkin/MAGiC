Sensitivity analysis

  1. Press Select component, then click a placed component on the board.
  2. Choose one parameter, its lower and upper bounds, and the number of curves (2 to 10).
  3. Run the comparison. Every other input in the circuit stays fixed.

Values are evenly spaced and include both endpoints. Cooperativity values must be integers. The x-axis range only changes the display; each simulation always runs the full 0 to 24 range.

Running a new comparison replaces the previous comparison. Cancel keeps completed curves. Ordinary Run Simulation does not add curves.
